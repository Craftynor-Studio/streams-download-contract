One file. One download job.

The Streams Download Contract lets any website describe resources and processing in an ordinary .streams.json download. Compatible apps download the manifest, validate it, fetch its resources, merge or mux them, and save the finished file.

For websites

Offer an HTTPS attachment or a generated Blob with the filename config.streams.json and MIME type application/vnd.streams-download+json. Regular browsers save the JSON; compatible apps process it automatically.

const blob = new Blob([JSON.stringify(manifest)], {
  type: "application/vnd.streams-download+json"
});
const url = URL.createObjectURL(blob);
const link = document.createElement("a");
link.href = url;
link.download = "config.streams.json";
document.body.append(link);
link.click();
link.remove();
setTimeout(() => URL.revokeObjectURL(url), 60000);

For apps

Show a single persistent progress item through manifest download, resource transfer, processing and final save. Keep configuration and temporary inputs internal. Validate the schema and the specification’s graph, resource and redirect rules before executing operations.

  • Direct downloads, MP4/WebM muxing, ordered fragment assembly and media concatenation.
  • Optional size, SHA-256, expiry and one bounded manifest refresh.
  • Public HTTPS resources, no executable commands or filesystem paths.
  • 512 KiB manifests, up to 256 resources and 64 ordered operations.
